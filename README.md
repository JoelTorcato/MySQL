# 📌 mysql study

## 📂 content  
here you'll find a variety of sql code, including:  
✅ database and table creation (create, drop)  
✅ data manipulation (insert, update, delete)  
✅ queries with select (basic and advanced)  
✅ joins between tables (inner join)  
✅ aggregate functions (count, avg, sum, max, min)  
✅ grouping and filtering (group by, having)  
✅ user management and permissions (grant, revoke)  
✅ primary and foreign keys relationships

## 🎯 purpose  
the goal of this repository is to serve as an archive of my database study and help others learning **mysql** and relational database concepts.  

building on my experience with **c** and **java**, i'm now learning how to design, manage, and query databases effectively!  

## 📎 how to use  
to run the sql scripts, use the mysql command line or any mysql client:  
```sh
mysql -u username -p < filename.sql
```

or import directly in mysql workbench, phpmyadmin, or similar tools.
